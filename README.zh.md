# 逆潮电台 · UNDERTOW FM

一款中文单人像素横版清关游戏。暴雨夜，港务台宣布低地已经撤空。修理工阿沅从废弃频道里听见敲门声，带着手摇发射机，从修理铺走向中央广播塔。在五段十二年前的现场录音里，玩家会接过她父亲阿烈的话筒，追查那张提前盖了章的撤离表。

战斗打磨以《怒之铁拳 4》为参考，重点是敌人出手前的预备动作、可辨的连续拳路、命中停顿，以及关卡间电子配乐的节奏变化。[对标作品发行方介绍](https://www.dotemu.com/games/streets-of-rage-4/)

## 开始游戏

Mac 打开 `UndertowFM.app`。Windows 和 Linux 发行包请先完整解压，让可执行文件和同名 `.pck` 处于同一目录，再启动游戏。游戏离线运行，配乐、字体和场景均随包提供。

选择「开始新航线」后可选故事、街机或暴潮难度。修理铺会实际演练移动、连续出拳、破防、闪避、脉冲和接入电台。进入新段、维修接点、接线盘及往事行动时会自动记录进度。「继续接力」读取本机的接力记录。「章节重播」可回到已接通的站点。

## 操作

| 动作 | 键盘 | 手柄（Xbox 标记） |
| --- | --- | --- |
| 移动／菜单选择 | WASD 或方向键 | 左摇杆／十字键 |
| 轻拳／重击 | J／K | X／Y |
| 闪避／脉冲 | 空格或 Shift／L | B／RB |
| 接入、取物、确认 | E 或回车 | A |
| 暂停／继续 | Esc | Start |
| 维修架跳跃／二段跳 | W、↑ 或空格，再按一次 | ↑ 或 B，再按一次 |
| 向下穿过脚手板 | 按住 S 或 ↓ 再按空格 | ↓ + B |
| 配线盘顺转／逆转 | E／K，或鼠标左右键 | A／Y |
| 故事难度配线提示 | J | X |
| 切换全屏 | F11 | 设置菜单 |

街战中，上下移动可改变纵深。连续三次轻拳有三种拳路，重击能打开盾卫的正面防御。命中或精准闪避可积攒频能，每次脉冲消耗 40 点。第三、七、十一站分别加入滑步追拳、破浪连踢和回声线圈。暂停菜单里的四页手册可随时查阅。

## 战役

- 今夜线包括修理铺和十五座接力站，共九十段街区任务。每站有独立地点、目击者和现场磁带。
- 十条架空检修路线共五十九个房间。五座旧式接线台共十五个电路谜题。
- A 面收录五段可操控的往事，共二十个地点、六十次现场行动。
- 九场精英战与三幕终局首领战。结局可决定两份记录的播出顺序。
- 三档难度、自动存档与备份、章节重播、磁带档案、音乐与音效音量、低动态和震动开关。

## 工程

以 Godot 4.7.2 打开本目录的 `project.godot`，运行主场景 `game/Main.tscn`。逻辑画幅为 640×360，使用 Compatibility 渲染器。像素图、曲谱和合成音色的制作源位于 `tools/art_actors`、`tools/art_world`、`tools/audio`。制作工具和验收脚本不进入游戏资源包。

三个桌面导出预设保存在 `export_presets.cfg`。安装对应版本的 Godot 导出模板后，在 macOS 工程根目录运行 `python3 tools/package_release.py` 可以构建并打包三平台。游戏内存档使用 Godot 的 `user://broadcast.cfg`，并保留上一份有效记录 `broadcast.cfg.bak`。macOS 默认目录为 `~/Library/Application Support/UndertowFM/`。

## 资源

角色、剧情、场景、交互、配乐、音效及制作代码为本工程创作。角色动作以逐帧像素图集绘制。九首电子原声共享一个三拍呼号，音频制作说明见 `tools/audio/README.md`。引擎使用 Godot，中文字体使用 Fusion Pixel Font。引擎、第三方组件及字体的许可原文位于 `licenses/`。
