逆潮电台 · UNDERTOW FM
版本 1.0.0    /    离线单人游戏

暴雨夜，港务台宣布低地已经撤空。
修理工阿沅却从一台收音机里，听见有人在敲门。

开始
  请完整解压。Mac 打开 UndertowFM.app。Windows 双击 UndertowFM.exe。
  Linux 运行 UndertowFM.x86_64。Windows 和 Linux 的 .pck 需与程序放在一起。
  标题选择「开始新航线」。六步修理铺教学会带你完成第一段接力。

键盘
  移动             WASD 或方向键
  轻拳 / 重击       J / K
  闪避 / 脉冲       空格或 Shift / L
  交互 / 确认       E 或回车
  暂停 / 设置       Esc
  全屏             F11

手柄
  移动             左摇杆或十字键
  轻拳 / 重击       X / Y
  闪避 / 脉冲       B / RB
  交互 / 暂停       A / Start

  维修架上按空格跳跃，再按一次可在空中追加一跳；按住下再跳可以落到下层。
  电路盘用 E 顺时针、K 逆时针旋转，也支持鼠标左右键。
  暂停菜单里可看四页手册，调整难度、音量、震动和低动态画面。

存档
  接力点自动保存在本机。退出后选择「继续接力」。
  标题的「声音档案」收录沿途捡到的磁带，可在通关后重播各站。
